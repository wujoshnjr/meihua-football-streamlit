# Operation STARK knowledge coverage

## 「完整」的定義

### 奇門遁甲

奇門不像《周易》只有固定 64 卦；一張盤由事件時間、陰陽遁、局數、九宮、天地盤、門、星、神、空馬與格局共同形成，實際盤象是組合式的。因此 Operation STARK 不假裝列出一個有限的「全部奇門卦象清單」，而採三層完整性：

1. **完整基礎語彙**：九宮、八門、九星、八神、十干、曆法／局法與核心狀態。
2. **完整固定關係矩陣**：81 天地盤干 + 72 星門 + 72 門宮 + 81 星宮，共 **306 個關係槽位**。每一格都有五行關係、一般解析、足球衍生義、可觀察訊號與反證條件。
3. **動態組合解析**：JARVIS 每次起局後，只把該盤實際出現的宮、門、星、神、干、306 關係子集、旬空、驛馬與格局交給知識檢索器，再交給 ChatGPT 合參。

`jarvis/qimen_relations.py` 是 306 關係矩陣；`interpretation.json` 與 `football_ontology.json` 保存解讀順序、判讀邊界與足球現代語義；`patterns.json` 保存自動可判定與 knowledge-only 格局。

### 梅花易數

梅花採固定 64 卦 catalog，因此資料庫要求：

- 八卦恰好 8 個，並保存卦數、五行、方位、萬物類象、旺衰及足球觀察／反證。
- 六十四卦恰好 64 個，1–64 無缺號。
- 8×8 上下卦組合恰好各出現一次。
- 每卦都有主題、一般解析與足球衍生義。
- 每次實際起卦額外合成本卦、互卦、變卦、動爻、體用、生克、旺衰及相關八卦類象。
- 六個動爻位置都有階段含意與足球觀察重點。
- 體用五種關係恰好覆蓋：生體、體生用、克體、體克用、比和。

梅花「完整解析」採組合式，而不是把同一段固定判語複製到每一種變化：六十四卦提供卦級主題；八卦類象提供上下卦細節；本／互／變描述時間層次；體用與旺衰描述受力；動爻描述轉折位置。AI packet 將這些層全部一起交給 ChatGPT。

## 足球語義邊界

「足球含意」是 Operation STARK 的現代應用層：用來告訴 ChatGPT 某個象可能對應哪些場上情境，以及什麼現象會反證。它不是古籍中的足球公式，也不是統計模型。

因此資料庫不保存：

- 生門 = 主勝 X%
- 克體 = 客勝 X%
- 某卦 = 固定比分

而保存：

- 可能的足球情境
- 可觀察訊號
- 反證條件
- 古典／專案來源層級

最終判讀必須由 `DIVINATION_PACKET_V1` 交給 ChatGPT 合參。
