# 從梅花易數版本遷移

## 不做自動資料轉換

梅花易數與奇門遁甲的輸入及狀態空間不相容：前者以卦、爻、體用等為核心，後者以事件時空、陰陽遁局、九宮四盤、值符值使等為核心。舊卦不能可靠地一對一轉成奇門盤，因此 6.0.0 不提供看似方便、實際失真的自動轉換。

## 可保留的通用概念

| 舊概念 | 新版處理 |
|---|---|
| 賽事身份與開賽時間 | 保留欄位，新增 IANA 時區與場地城市 |
| 賽前 freeze 規則 | 保留並強化為可驗證協議 |
| 來源 URL 與擷取時間 | 保留，新增類別、隊伍、重大更新與可靠度 |
| 報告與匯出 | 改為奇門方法、九宮、格局與情境 schema |
| 歷史評估 | 改為賽前鎖定的定性情境 top-k 評估 |

## 必須停用的舊欄位

起卦數字／文字筆畫、上卦、下卦、動爻、互卦、變卦、體卦、用卦、納甲、六親、卦辭、爻辭與易林索引。若需要保留舊研究紀錄，應封存在舊版獨立分支或匯出檔，不載入 6.0.0 引擎。

## 新的必要欄位

事件地民用時間、IANA 時區、場館、城市，以及固定方法版本。若改用真太陽時，還要新增經緯度、均時差算法與校正結果，並提升 schema 和方法版本。
