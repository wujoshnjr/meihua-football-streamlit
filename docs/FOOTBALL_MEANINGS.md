# 奇門符號的足球語義庫

版本：`football-semantic-composition-v2.0.0`

本文件說明專案如何把奇門盤中的宮、門、星、神、干支、旺衰、狀態與格局，轉成**可由賽前資料與比賽事件驗證或反證的足球候選情境**。這一層是現代應用規約，不是古籍原有的足球公式。

## 宣稱邊界

- 完整覆蓋目前 schema 定義的 108 個基礎語義單元。
- 任意合法的「9 宮 × 8 門 × 9 星 × 8 神」組合都能產生結構化解讀，共 5,184 組。
- 加入實際轉盤可見的 9 天盤干與 9 地盤干後，共覆蓋 419,904 個基礎結構。
- 旺衰、旬空、驛馬、刑墓迫、伏吟反吟及 39 個格局按命中條件疊加，不物化成大量重複文字。
- 「完整」指目前明示方法與資料 schema 的可計算全覆蓋；不宣稱窮盡所有奇門流派、抄本、口訣或未來足球事件模型。
- 結果不是勝負、固定比分、進球數、統計機率、期望進球或投注建議。

## 兩套知識必須分層

| 層 | 回答的問題 | 來源 | 能否宣稱為古法 |
|---|---|---|---|
| 古典奇門層 | 符號原本代表甚麼、格局如何成立 | 《遁甲演義》《奇門遁甲秘笈大全》及固定方法版本 | 可以，但須標明版本與流派差異 |
| 足球應用層 | 原義在足球中可能對應哪些行為 | 本專案映射規約、足球事件分類及官方規則 | 不可以；只能稱應用假說 |
| 外部證據層 | 這場比賽是否真的存在該條件 | 官方名單、傷停、賽程、場地、天氣及比賽事件 | 是現實資料，不改寫盤面 |

原典提供符號的語義邊界；StatsBomb、FIFA 與 IFAB 提供足球事件語彙。兩者之間的連結由本專案明示建立，不能倒過來說成古籍曾經定義「高位逼搶」或「VAR」。

## 組合次序

1. 宮位：情境與環境。
2. 八門：可以採取或受阻的行動通道。
3. 九星：能力、節奏與執行風格。
4. 八神：作用如何呈現、是否公開及其心理色彩。
5. 天盤干：外顯行動或觸發。
6. 地盤干：底層條件或承載。
7. 旺相休囚廢、空馬刑墓迫：修正作用的持續度、速度與摩擦。
8. 格局：只修飾已存在的結構，不單獨覆蓋前七層。
9. 外部證據：確認、削弱或反證候選情境。

主客仍依專案固定規約：主隊取日干，客隊取時干；日干或時干為甲時取值符星落宮。不得看盤後更換。

## 20 個足球分析維度

| 維度 | 可觀察內容示例 | 主要事件標籤示例 |
|---|---|---|
| 控球與節奏 | 傳球循環、主動降速、控場 | Pass、Carry、Half Start／End |
| 後場組織 | 門將出球、後場接應、第一線破解 | Pass、Goal Keeper、From Goal Kick |
| 推進與滲透 | 持球推進、盤帶、穿線、邊肋部進入 | Carry、Dribble、Ball Receipt |
| 機會創造 | 最後一傳、傳中、禁區進入 | Pass、Carry、Shot |
| 射門與終結 | 射門、射正、被擋、撲救、進球 | Shot 及其 outcome |
| 逼搶與施壓 | 高位壓迫、反搶、迫使倉促處理 | Pressure、Recovery、Interception |
| 攻守轉換 | 反擊、回防、奪球後快速向前 | From Counter、Recovery、Miscontrol |
| 防守結構 | 低位站位、封堵、解圍、禁區保護 | Block、Clearance、Interception |
| 對抗與二點球 | 爭頂、搶斷、碰撞、第二落點 | Duel、Foul Won、Recovery |
| 定位球 | 角球、自由球、界外球、球門球 | From Corner／Free Kick／Throw In |
| 守門與禁區處理 | 撲救、出擊、收球、清掃 | Goal Keeper、Shot Saved |
| 體能與傷停 | 疲勞、受傷、恢復與可用人手 | Injury Stoppage、Player Off／On |
| 犯規與紀律 | 犯規、黃紅牌、人數變化 | Foul Committed、card、Player Off |
| 裁判與 VAR | 覆核、越位、點球、可改判事件 | VAR review、offside、penalty |
| 換人與變陣 | 先發、替補、位置互換、結構切換 | Starting XI、Substitution |
| 團隊協作 | 接應、傳接網絡、角色互補 | Pass、Receipt、Pressure |
| 心理與聲勢 | 主場壓力、慌亂、爭議後反應 | Miscontrol、Foul、Shot |
| 資訊與名單 | 官方名單、傷停消息、傳聞、保密 | Starting XI、source update |
| 場地旅途環境 | 草皮、天候、遠征、休息間隔 | venue／weather／travel update |
| 比賽狀態與停頓 | 領先後策略、死球、傷停補時 | Half End、Injury Stoppage、restart |

前 16 個維度主要可連接事件資料；心理、資訊、場地旅途等維度通常需要官方公告或賽前來源，不應只靠事件資料臆測。

## 108 個基礎語義單元

| 類別 | 數量 | 功能 |
|---|---:|---|
| 九宮 | 9 | 比賽環境與空間條件 |
| 八門 | 8 | 行動通道與功能 |
| 九星 | 9 | 能力與執行風格 |
| 八神 | 8 | 表現方式與顯隱色彩 |
| 天干 | 10 | 角色、觸發與底層條件；甲依值符定位 |
| 地支 | 12 | 時空、移動與環境類比 |
| 旺相休囚廢 | 5 | 作用的持續度與可發用程度 |
| 結構狀態 | 8 | 旬空、驛馬、入墓、擊刑、門迫、宮迫、伏吟、反吟 |
| 格局 | 39 | 奇儀格、三遁、三詐、五假、庚格及盤勢修飾 |
| 合計 | 108 | 每筆都有可能表現、可觀察訊號及反證 |

完整逐條內容位於 `knowledge/football_ontology.json`，介面「足球義理庫」可以用「高位逼搶」「VAR」「傷停」「門將」「定位球」「反擊」等足球詞反向搜尋所有相關奇門符號。

## 五行互動如何加入解讀

組合器另外列出宮門、星宮、星門及天地盤干的五行關係：

- 同五行：訊號容易重複或放大，也可能形成單一打法。
- 前層生後層：前層為後層提供條件。
- 後層生前層：後層反向支援，但可能消耗自身資源。
- 前層剋後層：存在直接限制或摩擦。
- 後層剋前層：前層作用可能受壓、延遲或變形。

這些關係只描述層間條件，不換算為分數、勝率或進球數。門迫與宮迫仍依方法版本中的固定定義判定。

## 組合例

假設某宮為「震三宮＋傷門＋天沖＋白虎」：

- 宮、門、星同屬木，快速啟動、逼搶與轉換語義重疊。
- 白虎加入對抗、犯規與急性傷勢的表現方式。
- 可觀察訊號包括前場 pressure、奪球後快速向前、duel、foul 與 injury stoppage。
- 反證包括實際壓迫強度低、比賽節奏慢、犯規與碰撞均少。
- 若同時旬空，應先考慮「預期高壓未落地或延後」；不能一面保留高壓解讀，一面忽略旬空。

這個例子仍不能直接推成某隊必勝、一定有紅牌或一定出現傷退。

## 證據與反證規則

- 每個足球義至少有一個可觀察訊號與一個反證條件。
- 賽前來源仍受 `freeze_at = event_at - 6 hours` 約束；重大更新後兩隊必須同步刷新。
- 傷病、先發與停賽優先使用球會、賽會或官方名單；傳聞只能以低可靠度保存。
- 事件標籤是觀察口徑，不代表因果。例如 pressure 增加可支持「施壓情境」，不能證明某個奇門符號造成施壓。
- 多個情境可以同時成立；保留互相競爭的解釋比事後選一個故事更重要。
- 賽後資料只能評估賽前鎖定的假說，不能回灌或改寫原判讀。

## 一手來源

- [《遁甲演義》](https://zh.wikisource.org/zh-hant/%E9%81%81%E7%94%B2%E6%BC%94%E7%BE%A9)：九宮、八門、九星、三奇六儀、值符值使與常用格局的原典比對。
- [《奇門遁甲秘笈大全》](https://ctext.org/wiki.pl?chapter=828124&if=gb&remap=gb)：星、門、宮與判讀次序的版本比對。
- [Hudl StatsBomb Open Data](https://github.com/hudl/open-data)：matches、events、lineups 與部分 360 資料的 JSON 結構及事件分類。
- [FIFA Football Language](https://inside.fifa.com/innovation/football-data)：跨賽事足球分析共同框架。
- [IFAB Laws of the Game](https://www.theifab.com/laws-of-the-game-documents/)、[Law 12](https://www.theifab.com/laws/latest/fouls-and-misconduct/) 與 [VAR Protocol](https://www.theifab.com/laws/latest/video-assistant-referee-var-protocol/)：犯規、紀律、重新開始及影像覆核的正式語境。
- [StatsBomb：Modelling Team Playing Style](https://blogarchive.statsbomb.com/articles/soccer/modelling-team-playing-style/)：持球與無球事件用於比賽風格描述的方式。

來源用來定義奇門原義或足球事件語彙；「哪個奇門符號可能對應哪種足球行為」仍是本專案應用規約，版本更新時必須升級 mapping version 並保留歷史輸出。
